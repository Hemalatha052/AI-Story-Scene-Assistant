# AI Story & Scene Assistant

## Overview

Developed an AI-powered application using Python, Streamlit, and Gemini API that transforms user-provided story ideas into structured storyboard scenes.

## Features

- Story idea input
- AI-powered scene generation
- Interactive Streamlit interface
- Gemini API integration
- Creative storyboard creation

## Technologies Used

- Python
- Streamlit
- Gemini API
